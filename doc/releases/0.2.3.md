Zotero AI Sidebar 的首个公开版本：在 Zotero 10 侧栏中使用你自己的云端模型阅读文献、连续提问。

插件免费开源，无插件会员订阅；模型 API 的额度与费用由所选服务商决定。

## 下载与安装

下载 **zotero-ai-sidebar-0.2.3.xpi**，在 Zotero 的“工具 → 插件 → 齿轮 → 从文件安装插件…”中选择该文件，重启 Zotero。

选中文献或 PDF，打开右侧“AI 文献助手”，在设置中填写兼容 Chat Completions 的接口地址、模型名和自己的 API Key。

## 功能

- 每篇文献可创建、切换、重命名、删除多个对话，并保存草稿。
- 打开文献只读取题名与摘要；点击“阅读正文”或明确要求阅读全文后才提取 PDF 正文。
- 聊天记录支持自定义保存文件夹、迁移、备份与恢复。
- 支持 Markdown、KaTeX 数学公式、mhchem 化学式、表格和代码块。
- 支持流式输出、停止生成、复制回答、PDF 选文和字号调节。
- 修正按钮文字垂直对齐，适配深色模式。

## 兼容性与限制

- 面向 Zotero 10.x；主要在 Windows 环境开发和使用，其他系统尚未进行界面验证。
- PDF 需要文字层；扫描件需要先进行 OCR。正文上限为 300,000 字符，超过上限会提示，避免悄悄截断。
- 发送问题时，所选文献上下文与对话历史会发送到你配置的模型服务商；API Key 保存在本机 Zotero 配置中。
- 验证包括构建、TypeScript、Lint、本地存储迁移及恢复、数学与化学式渲染；Zotero headless 自动测试在当前环境启动超时。
